## 1. TPM conventions (where reimplementations die)

Files: `pyphi/convert.py`, `pyphi/tpm.py`, `docs/conventions.rst` (1.2.1).

### Three accepted input forms (all converted to one canonical form)
1. **State-by-state**: square `(2^n, 2^n)`; entry `(i,j)` = P(state j at t+1 |
   state i at t). Row AND column indices are **little-endian**.
2. **State-by-node, 2-D**: `(2^n, n)`; entry `(i,j)` = P(node j ON at t+1 |
   state i at t). Row indices little-endian.
3. **State-by-node, multidimensional** ("md"): shape `[2]*n + [n]`. This is the
   **canonical internal form**. `tpm[(s0,s1,...,s_{n-1})][j]` = P(node j ON at
   t+1 | given previous state tuple). Networks always store this form
   (`Network._build_tpm`).

### Little-endian ("LOLI") convention
- The state tuple's element *i* is the state of node *i*. Decimal row index:
  **node 0 is the least-significant bit**. `convert.state2le_index((1,0,0)) == 1`;
  `le_index2state(i, n) = tuple((i >> k) & 1 for k in range(n))`.
- `to_multidimensional` = `tpm.reshape([2]*N + [N], order="F")` — **Fortran
  order is what encodes little-endian rows**. Same trick in reverse for
  `to_2dimensional`. Flattening repertoires uses `ravel(order='F')`
  (`distribution.flatten`, little-endian by default).
- Big-endian helpers exist (`be2le`, `state2be_index`, …) purely for I/O
  conversion. Historical names: LOLI (low-order bits = low-index nodes) = le,
  HOLI = be; renamed at 1.0.0.
- **Doc bug (1.2.1)**: the docstring of `convert.state_by_node2state_by_state`
  claims the result follows the *big-endian* convention; the code uses
  `le_index2state`/`state2le_index`, i.e. **little-endian** throughout. Trust
  the code and the doctest in `state_by_state2state_by_node` (little-endian).

### Conversion sbs ↔ sbn and conditional independence
- `state_by_state2state_by_node`: for each previous state row, the probability
  node n is ON = sum of row mass over next-states where n is ON (a
  marginalization). **Conditional dependencies are silently lost** (docstring
  "danger" note).
- `state_by_node2state_by_state`: product over nodes of `p_n` (ON) or `1-p_n`
  (OFF) — i.e., *assumes* conditional independence; deterministic TPMs take a
  fast path writing a single 1 per row.
- On `Network` construction, `validate.tpm(tpm, check_independence=
  config.VALIDATE_CONDITIONAL_INDEPENDENCE)` (default True) checks a
  state-by-state TPM equals the round-trip
  `sbn2sbs(sbs2sbn(tpm))`; state-by-node input is conditionally independent by
  construction. IIT 3.0/PyPhi *requires* conditional independence; the "virtual
  units" doctrine says conditionally dependent TPMs must be modeled by adding
  hidden units.

### Connectivity matrix
- `cm[i][j] == 1` means **edge from node i to node j** (row = source, column =
  sink). Verified in `connectivity.get_inputs_from_cm` (inputs of `v` = rows `i`
  with `cm[i][v]`) and `get_outputs_from_cm`.
- If `cm=None`, PyPhi assumes **all-ones** (fully connected incl. self-loops).
  The cm is only ever used to *prune* (purviews, reducibility, strong
  connectivity); a too-permissive cm changes nothing numerically but costs time.
  `tpm.infer_cm` can infer the cm from the md TPM (edge i→j iff ∃ context where
  flipping i changes column j).
- Cuts operate on the cm: `Cut(from_nodes, to_nodes).apply_cut(cm)` zeroes
  `cm[i][j]` for i∈from, j∈to (unidirectional severing). The TPM is untouched:
  severed inputs simply become "non-inputs" of the node and get
  **marginalized out** (uniform noise) when node TPMs are rebuilt.

### Node TPMs (`pyphi/node.py`)
Each `Node` holds `tpm` of shape `(2,)*n + (2,)`: first n dims = previous state
of the network (size 2 only for that node's *inputs* per the cut cm; singleton
otherwise), last dim = this node's next state (index 0 = OFF prob, 1 = ON prob).
Built as: take `subsystem.tpm[..., i]` (ON probs), `marginalize_out` non-input
subsystem nodes, stack `[1-p, p]` on a new last axis.

### Core tensor ops (`pyphi/tpm.py`)
- `condition_tpm(tpm, fixed_nodes, state)`: index dim i with `state[i]` +
  `np.newaxis` → keeps ndim, collapses fixed dims to singletons (broadcastable).
- `marginalize_out(indices, tpm)`: `tpm.sum(dims, keepdims=True) / prod(sizes)`
  — i.e., **mean** over those axes (uniform marginalization).
- `expand_tpm`: broadcast singletons to full `[2]*...` via multiply by ones.

## 2. Network / Subsystem model (1.2.1)

- `Network(tpm, cm=None, node_labels=None)`: immutable; hashes tpm+cm. Labels
  via `NodeLabels` (default 'A','B',...; `coerce_to_indices` accepts labels or
  ints everywhere).
- `Subsystem(network, state, nodes=None, cut=None)`:
  - `state` is the state of the **whole network** (length = network size), not
    of the subsystem; `proper_state` = restriction to subsystem nodes.
  - `external_indices` = network nodes ∉ subsystem. **Background conditions =
    FROZEN**: `self.tpm = condition_tpm(network.tpm, external_indices, state)`
    — external nodes are fixed at their *current* state for both cause and
    effect computations (post-2014-literature convention; contrast IIT 4.0's
    causal marginalization, see §4/§0 main presets). Their dims stay as
    singletons; subsystem TPM keeps network ndim.
  - `validate.subsystem` → `state_reachable`: the (conditioned) state must have
    nonzero probability from some previous state, else `StateUnreachableError`
    (config `VALIDATE_SUBSYSTEM_STATES=True`).
  - `cut` (default `NullCut`) is applied **to the cm only**; node TPMs then
    marginalize severed inputs.
  - Caches: repertoire cache, single-node repertoire cache, MICE cache
    (invalidation-aware w.r.t. cuts).
- `MacroSubsystem(network, state, nodes, time_scale=1, blackbox=None,
  coarse_grain=None)` (`pyphi/macro.py`): squeezes external singleton dims and
  reindexes to 0..n; pipeline = squeeze → blackbox partial-freeze → temporal
  blackboxing (`run_tpm` over `time_scale` steps) → spatial blackbox (hidden
  units frozen; only `output_indices` remain) → spatial coarse-grain
  (`CoarseGrain(partition, grouping)` maps micro-states to macro-states by
  summing probabilities per state-group). `MacroNetwork`/`emergence()` searches
  all coarse-grains/blackboxes for max Φ.

## 3. Core computation (1.2.1 = IIT 3.0)

### Repertoires (`subsystem.py`)
- `cause_repertoire(M, Z)`:
  - `Z == ()` → `np.array([1.0])` (multiplicative identity).
  - `M == ()` → `max_entropy_distribution(Z)` (uniform over purview).
  - Else: **product over mechanism nodes m** of single-node cause repertoires:
    `node.tpm[..., state_m]` (probability of m's observed state given each
    previous state of its inputs), `marginalize_out(inputs(m) − Z)`, then
    elementwise product (implicit uniform prior via broadcasting over
    `repertoire_shape(Z, n)`), then **normalize to sum 1** (Bayes).
- `effect_repertoire(M, Z)`: product over **purview nodes z** of
  `condition_tpm(node_z.tpm, inputs(z) ∩ M, state)`,
  `marginalize_out(inputs(z) − M)` → each factor already a distribution over
  z's next state; no normalization.
- Repertoires are arrays of shape `repertoire_shape(purview, n)` =
  `[2 if i∈purview else 1 for i in range(n)]` — distributions over **purview
  states**, embedded in network-shaped tensors for broadcasting.
- `partitioned_repertoire` = elementwise product of the parts' repertoires.
- `expand_repertoire`: multiply by unconstrained repertoire over the missing
  nodes, then normalize (used for concept distances & display).

### Small phi / MIP
- `find_mip(direction, M, Z)`: iterate `mip_partitions` (per
  `config.PARTITION_TYPE`), `phi = repertoire_distance(direction, unpartitioned,
  partitioned)` (rounded to `PRECISION`), **return immediately on phi == 0**,
  else keep strictly smaller (`phi < mip.phi` → first minimal partition
  encountered wins ties). Cause repertoire identically 0 (unreachable within
  purview) → phi 0.
- Partition schemes (`pyphi/partition.py`, registry `partition_types`):
  - `'BI'` (default; canonical IIT 3.0): `mip_bipartitions` — product of
    undirected bipartitions of the mechanism × **directed** bipartitions of the
    purview, excluding pairs where a whole side (mech_i ∪ purv_i) is empty.
    Enumeration order = bit-counting order of `bipartition_indices` (part0/part1
    assignment by bits, note parts emitted as `(part[1], part[0])`).
  - `'TRI'`: `wedge_partitions` — strict mechanism bipartitions × directed
    purview **tripartitions** with third mechanism part always ∅; normalized,
    deduplicated, "compressible" tripartitions dropped.
  - `'ALL'`: `all_partitions` — every set-partition of the mechanism (plus an
    empty part) × k-partitions of the purview with empty-padding permutations;
    excludes partitions leaving the full mechanism intact over a nonempty part.
- `phi(M, Z) = min(phi_cause_mip, phi_effect_mip)`.

### MICE / concepts
- `potential_purviews(direction, M)`: powerset of subsystem nodes filtered by
  `irreducible_purviews(cm, ...)` — drops purviews that are **block-reducible**
  w.r.t. the cm (`connectivity.block_reducible` on the relevant submatrix;
  cause: purview→mechanism, effect: mechanism→purview). Cached at Network level
  for the full cm, re-filtered per-subsystem for the cut cm.
- `find_mice = max(find_mip(d, M, Z) for Z in purviews)` with RIA ordering
  `order_by = [phi, len(mechanism), len(purview)]`
  (with `PICK_SMALLEST_PURVIEW=True`: `-len(purview)`). Python `max` keeps the
  **first** encountered among fully-tied items; purview enumeration is powerset
  order (increasing size, lexicographic within size). So default tie-break:
  **larger purview wins; among same-size ties, earlier (lexicographically
  smaller) purview wins.**
- `phi_max(M) = min(mic.phi, mie.phi)`. `Concept` = (mechanism, MIC, MIE);
  `concept.phi = min(cause.phi, effect.phi)`. Concepts with `phi > 0` enter the
  CES (`compute/subsystem.py::ComputeCauseEffectStructure.process_result`).
  Mechanisms enumerated = nonempty powerset of subsystem nodes.
- Null concept: unconstrained cause & effect repertoires of the empty mechanism
  over the empty purview... (actually `cause_repertoire((), ())` etc.), used as
  EMD "reference point".

### Distances (`pyphi/distance.py`)
- Registry `measures`; `config.MEASURE` default `'EMD'`. Others: `'L1'`,
  `'KLD'` (asymmetric), `'ENTROPY_DIFFERENCE'`, `'PSQ2'`, `'MP2Q'` (asym),
  `'KLM'`/`'BLD'` (asym). Asymmetric measures are forbidden at system level.
- `'EMD'` small-phi path is **direction-dependent** (`directional_emd`):
  - **Cause**: `hamming_emd` — `pyemd.emd(flatten(d1), flatten(d2),
    _hamming_matrix(N))` where N = ndim after squeeze (number of purview
    nodes); ground metric = Hamming distance between purview states
    (precomputed for N<10, joblib-cached above). Flatten is order='F'
    (little-endian).
  - **Effect**: `effect_emd` — analytic: `sum_i |P1(node_i=OFF) −
    P2(node_i=OFF)|` (valid because effect repertoires are product
    distributions). **Not** the same value as full EMD on the joint for
    correlated cause repertoires — a real asymmetry to replicate.
  - Result rounded to `config.PRECISION` (=6).
- System level (`compute/distance.py`):
  - `concept_distance(c1,c2)` = EMD(expanded cause reps over union cause
    purview) + EMD(expanded effect reps over union effect purview) — both via
    `system_repertoire_distance` = full `hamming_emd` for MEASURE='EMD'.
  - `ces_distance(C1,C2)`: if one CES's concepts are a subset (by `emd_eq`:
    same phi/mechanism/repertoires) of the other → `_ces_distance_simple`:
    Σ phi_c · d(c, null_concept) over destroyed concepts. Otherwise
    `_ces_distance_emd` (the **extended EMD**): pairwise concept-distance
    matrix between the CESs' unique concepts plus a null-concept row/column;
    within-CES moves blocked via a large constant (max+1); mass = each
    concept's phi; deficit mass assigned to the null concept on the smaller
    side; solve one EMD. Rounded to PRECISION.
  - `config.USE_SMALL_PHI_DIFFERENCE_FOR_CES_DISTANCE=True` replaces all this
    with |Σφ(C1) − Σφ(C2)|.

### Big phi (`compute/subsystem.py`, `compute/network.py`)
- `sia(subsystem)`: memoized (joblib) keyed on subsystem hash + the
  result-affecting config (`_sia_cache_key`). Short-circuits to null SIA (Φ=0)
  if: empty; **not strongly connected** (per cut cm); or a single micro node
  (without self-loop always; with self-loop unless
  `SINGLE_MICRO_NODES_WITH_SELFLOOPS_HAVE_PHI=True`); or the unpartitioned CES
  is empty.
- Cuts: `sia_bipartitions` = **directed bipartitions** of the subsystem nodes,
  nontrivial (both parts nonempty) → `Cut(part0 ✕→ part1)`; 2^n − 2 cuts.
  `CUT_ONE_APPROXIMATION=False` default (else only single-node in/out cuts).
- `evaluate_cut`: recompute CES of the cut subsystem, restricted to mechanisms
  that were concepts in the uncut CES ∪ mechanisms split by the cut (exact per
  IIT 3.0; `ASSUME_CUTS_CANNOT_CREATE_NEW_CONCEPTS=False` default), then
  `Φ_cut = ces_distance(unpartitioned_ces, partitioned_ces)`. SIA = min over
  cuts; SIA ordering `[phi, len(subsystem), node_indices]`; evaluation
  short-circuits on Φ=0. **Cuts are evaluated in parallel by default**
  (`PARALLEL_CUT_EVALUATION=True`) with `process_result` keeping strictly
  smaller — among exactly-tied cuts the winner depends on completion order ⇒
  potential nondeterminism in reported MIP cut (Φ value unaffected).
- `major_complex(network, state)` = max SIA over `possible_complexes` (subsets
  of `causally_significant_nodes`, states validated); ties → larger subsystem,
  then larger node_indices tuple.
- `SYSTEM_CUTS='3.0_STYLE'` default; `'CONCEPT_STYLE'` = experimental
  concept-style cuts (`ConceptStyleSystem`, KCuts from mechanism partitions of
  the full node set; min over cause- and effect-side SIAs).
- Actual causation (`pyphi/actual.py`): `Transition(network, before_state,
  after_state, cause_indices, effect_indices)`, `alpha` via pointwise ratios,
  accounts, AC SIAs — separate module, IIT 3.0-era definitions (Albantakis
  et al. 2019).

### Tie-breaking summary (exact rules, 1.2.1)
1. Small-phi MIP: first partition in generator order achieving the minimal
   (rounded) phi; immediate return on phi=0.
2. MICE purview: `max` over RIAs ordered by (phi, |mechanism|, |purview|);
   first-encountered wins full ties; `PICK_SMALLEST_PURVIEW` flips the purview
   term.
3. Concept phi: min(cause, effect).
4. SIA cut: minimal (phi, subsystem size, node indices); first computed wins
   ties (nondeterministic under parallel map).
5. Complexes: `max` over SIAs.
All phi comparisons happen on values pre-rounded to `PRECISION=6`; `EPSILON =
10**-PRECISION` used for approximate equality (`utils.eq`).

### IIT 4.0 pipeline (`feature/iit-4.0` @ b78d0e34)

Everything below coexists with the legacy 3.0 code (old `compute/subsystem.py`
`sia()` still present); `Subsystem.sia()` delegates to the new pipeline.

- **Two subsystem TPMs**: `effect_tpm` = network TPM conditioned on background
  (as in 3.0) and `cause_tpm = tpm.backward_tpm(network.tpm, state,
  node_indices)` — the IIT 4.0 backward TPM (paper Eq. 4 "extended
  background": background past causally marginalized conditional on current
  state), applied unconditionally on this branch.
- **Mechanism level**: `intrinsic_information(direction, M, Z)` computes for
  each purview state the GID between forward repertoire and unconstrained
  forward repertoire weighted by selectivity, and **argmaxes over purview
  states** (specified state; ties → `STATE_TIE_RESOLUTION`). φ of a partition
  (GID branch of `evaluate_partition`):
  `φ = selectivity * log2(forward_p / partitioned_forward_p)` where
  `selectivity = repertoire[specified_state]`, partitioned forward probability
  = product over partition parts of forward probabilities. MIP search over
  `PARTITION_TYPE='ALL'` partitions with normalization
  `normalized_phi = phi / num_connections_cut`, ties via
  `MIP_TIE_RESOLUTION`; `find_mip` maps over all tied specified states then
  `resolve_ties.states`. MICE over purviews via `PURVIEW_TIE_RESOLUTION`
  (max φ); ties are *carried* (`.ties`) not just broken.
- **Forward repertoires** (`pyphi/repertoire.py`): `forward_effect_repertoire`,
  `forward_cause_probability` (role-swap trick using effect repertoire with
  CAUSE direction), unconstrained variants (effect: mean over mechanism
  states; cause: constant fill with mean forward cause probability — paper
  Eq. 32).
- **System level** (`pyphi/new_big_phi/__init__.py`, single file):
  1. `system_intrinsic_information`: cause/effect intrinsic information of the
     full system over itself → specified cause & effect **system states**.
  2. Partitions from `SYSTEM_PARTITION_TYPE='SET_UNI/BI'` (set partitions ×
     per-part direction). For each: apply cut, compute forward probability of
     the specified state under the cut,
     `φ = min(φ_cause, φ_effect)`, `normalized_phi = φ *
     partition.normalization_factor()`.
  3. MIP = min over partitions by hardcoded key `(normalized_phi, -phi)`;
     ties collected onto the SIA. Short-circuit conditions enum: NO_SUBSYSTEM,
     NO_STRONG_CONNECTIVITY, MONAD_WITH_NO_SELFLOOP, MONAD_..._ZERO_PHI,
     NO_CAUSE/NO_EFFECT (when intrinsic info ≤ 0 and `SHORTCIRCUIT_SIA`),
     NO_VALID_PARTITIONS.
- **Φ-structure**: `phi_structure(subsystem)` = SIA + CES (distinctions,
  congruence-resolved against the specified system state) + relations;
  `PhiStructure.big_phi = Σφ_d + Σφ_r`.
- **Relations** (`pyphi/relations.py`, rewritten): `Relation(frozenset)` over
  distinction faces; faces from `product(Direction.all(), repeat=k)`;
  `φ_r = |congruent_overlap| * min_relatum(φ / |purview_union|)`. Candidate
  sets with nonempty congruent overlap enumerated via **graphillion** setsets
  (`combinatorics.union_powerset_family`). Backends: CONCRETE (enumerate),
  ANALYTICAL (closed-form Σφ_r via `sum_of_minimum_among_subsets` +
  inclusion–exclusion counts).
- `maximal_complex` / `irreducible_complexes`: serial; note
  `SystemIrreducibilityAnalysis.__bool__` = `is_positive(phi)` and **GID φ_s
  can be negative** (see fixtures), such systems count as reducible.

## 4. Configuration

### 1.2.1 (`pyphi/conf.py`, loads `pyphi_config.yml` from cwd at import)
Options that change numbers (defaults in bold):
- `MEASURE` (**'EMD'**): small-phi & system repertoire distance (EMD, L1, KLD,
  ENTROPY_DIFFERENCE, PSQ2, MP2Q, KLM/BLD; registry-extensible).
- `PARTITION_TYPE` (**'BI'**): 'BI' | 'TRI' | 'ALL' (registry-extensible).
- `SYSTEM_CUTS` (**'3.0_STYLE'**): or 'CONCEPT_STYLE'.
- `PICK_SMALLEST_PURVIEW` (**False**).
- `USE_SMALL_PHI_DIFFERENCE_FOR_CES_DISTANCE` (**False**).
- `PRECISION` (**6**): rounding of every distance; ties are defined at this
  precision. Changing it changes results.
- `VALIDATE_SUBSYSTEM_STATES` (**True**), `VALIDATE_CONDITIONAL_INDEPENDENCE`
  (**True**).
- `SINGLE_MICRO_NODES_WITH_SELFLOOPS_HAVE_PHI` (**False**).
- `ASSUME_CUTS_CANNOT_CREATE_NEW_CONCEPTS` (**False**),
  `CUT_ONE_APPROXIMATION` (**False**) — approximations, off by default.
- Parallelism (affects tie identity, not phi): `PARALLEL_CONCEPT_EVALUATION`
  (**False**), `PARALLEL_CUT_EVALUATION` (**True**),
  `PARALLEL_COMPLEX_EVALUATION` (**False**), `NUMBER_OF_CORES` (**-1** = all).
- Caching/logging options (no numeric effect): CACHE_SIAS, CACHE_REPERTOIRES,
  CACHING_BACKEND ('fs'), REDIS_CACHE, MAXIMUM_CACHE_MEMORY_PERCENTAGE, ...

**Canonical IIT 3.0 = the 1.2.1 defaults** (EMD + BI + 3.0_STYLE + PRECISION 6
+ frozen background). This is what `test/test_big_phi.py` asserts.

## 6. Generality limits (checklist)

- **Binary units only** in 1.2.1 **and on `feature/iit-4.0`**: `[2]*n` shapes
  hard-coded in `convert`, `distribution.repertoire_shape`, `node.py`, Hamming
  matrices; "TODO extend to nonbinary nodes" throughout; `num_states = 2**n`.
  On the iit-4.0 branch the TPM is wrapped in `ExplicitTPM`
  (`data_structures.ArrayLike` proxy over `np.ndarray`) but `_validate_shape`
  still enforces `(2^N, N)` / `[2]*N+[N]`; **no `num_states_per_node`
  anywhere** on that branch. Nonbinary exists only as the stale unmerged
  `origin/nonbinary` branch (2021, PR #48) and, properly, on main 2.0
  (per-node alphabets, `FactoredTPM`).
- **Stochastic TPMs**: fully supported (probabilities anywhere in [0,1]);
  determinism only exploited as a fast path in conversion. Conditional
  independence **required** (validated; dependencies silently destroyed by
  conversion otherwise).
- **State must be reachable** given frozen background, else exception.
- **Macro**: `pyphi/macro.py` supports coarse-graining (state groupings),
  spatial blackboxing (hidden units frozen), temporal blackboxing
  (`time_scale`), and exhaustive emergence search — 1.2.1 API is
  `MacroSubsystem`/`emergence()`; main 2.0 implements the Marshall et al. 2024
  intrinsic-units framework.
- **Actual causation**: `pyphi/actual.py` (Transitions, alpha, accounts) in
  1.2.x and iit-4.0; formalism module on main.
- **Practical size limits**: everything is exponential — 2^n TPM rows, powerset
  of mechanisms × powerset of purviews × partitions, 2^n−2 system cuts, and
  (4.0) exponentially many relations. Realistic full-SIA limit ~6–8 binary
  nodes on 1.2.1 (docs/paper: networks >10 nodes generally infeasible without
  approximations); memory for Hamming matrices grows as 4^n (N=13 → 512 MB).
  GitHub #115 "Scalability to large network" closed as inherent.
- **No gradients, no vectorization across systems**: pure NumPy + Python loops;
  one subsystem/state at a time; caches (joblib fs cache, optional Redis) are
  the only reuse mechanism.
- **Parallelism**: 1.2.1 uses `multiprocessing` MapReduce (fork-based, config
  propagated to workers — bug fixed in 1.2.1); iit-4.0 branch uses **Ray**
  (`pyphi/parallel/`); main supports distributed computation. Windows
  officially unsupported in 1.2.x (use conda).
- **pyemd dependency** (1.2.1): C++ extension, brittle on new
  Python/NumPy; main replaced it (POT backend).

## 7. Known quirks

- **EMD solver noise**: pyemd returns approximate optima; analytically-zero Φ
  can appear as ~1e-7..1e-6. Hence `PRECISION=6` rounding everywhere and
  `EPSILON`-based comparisons. main's `iit3` preset keeps precision 6 with a
  comment that the EMD tolerance "was unreliable at finer precisions under the
  historical pyemd backend, and the published goldens are calibrated to it."
- **Cause vs effect EMD asymmetry** (analytic effect EMD) — see §3; using full
  EMD on both sides will *not* reproduce PyPhi's effect-phi values whenever
  purview marginals interact.
- **Tie-breaking instability**: MIP/MICE/SIA ties resolved by enumeration order
  (documented above); under parallel cut evaluation the winning *cut object*
  for tied Φ is nondeterministic. The iit-4.0 branch added `resolve_ties.py`
  + config to make this explicit; main makes every tie policy a config knob.
- **Doc/code endianness mismatch** in 1.2.1 `convert.state_by_node2state_by_state`
  docstring (says big-endian; is little-endian).
- **Host endianness**: GitHub #41 — test failure on s390x (big-endian
  hardware); NumPy byte-order assumptions.
- Frozen background can make the observed state unreachable → PyPhi raises;
  also means Φ of a subsystem depends on states of *external* nodes.
- `SINGLE_MICRO_NODES_WITH_SELFLOOPS_HAVE_PHI` default differs across eras:
  False in 1.2.1, **True** in main's global defaults (3.0 preset sets False).
- The CES distance takes a "simple" path when one CES ⊆ other (sum of
  phi·distance-to-null) and the extended-EMD path otherwise — both must be
  implemented to match all cases.
- 1.2.1 `config` loads `pyphi_config.yml` from the *current directory* at
  import time — silent result changes if such a file exists.
- Historical: 1.1.0 fixed the `disjunction_conjunction` example's cm; ancient
  results may differ.
- GitHub #28: CPU leak reports with multiprocessing; long-running processes
  should set `PROGRESS_BARS=False`, control `NUMBER_OF_CORES`.

### feature/iit-4.0-specific quirks
- **Negative system φ** possible under GID (basic_noisy_selfloop golden =
  −0.382); `__bool__`/complex-search treat it as reducible.
- Dead code in `new_big_phi.sia` (~L350): `if partitions == "GENERAL":` can
  never be true (should test the scheme name) → with
  `SYSTEM_PARTITION_TYPE="GENERAL"` the `is_disconnecting_partition` filter is
  never applied.
- System-MIP tie policy hardcoded (`(normalized_phi, -phi)`), bypassing
  `MIP_TIE_RESOLUTION` — replicate the hardcoded key, not the config.
- SIA ties (`_ties`) are dropped on JSON serialization (warning).
- `docs/examples/index.rst` doctests reference `Subsystem(...,
  backward_tpm=True)` and a `pyphi.backwards` module that don't exist on the
  branch (numbers there come from a later lineage; not collected by pytest).
- Version-string pinning of golden JSONs (`2.0.0a1`) — see §8.
- `backward_tpm` (extended background) is applied **unconditionally**; there is
  no config knob on this branch (main 2.0 makes it
  `background_conditioning ∈ {CAUSAL_MARGINALIZATION, CONDITION_CURRENT_STATE}`).

  4 other tests marked `outdated`, reference removed APIs),
  `test_repertoire.py` (invariants), `test_resolve_ties.py`,
  `test_metrics*.py` (registry pinning + numerics for ID/AID; **no direct

- **Pitfalls**: golden JSONs embed `__version__: "2.0.0a1"` and
  `jsonify._check_version` raises on mismatch → tests pass only if the
  installed version resolves to exactly `2.0.0a1` (no such git tag exists —
  depends on tag state at install). `test_iit4.py`/`test_relations.py` use
  CWD-relative `test/data/...` paths (must run pytest from repo root). Repo
  root contains a `pyphi_config.yml` that is silently loaded when running
  from there.
- Parallelism: Ray-based recursive map-reduce tree (`pyphi/parallel/`),
  chunked via `more_itertools.chunked_even`, branch factor 2, backpressure
  (inflight limit 1000), short-circuit via `ray.cancel`; config propagated to
  workers through a YAML snapshot in the disk cache. Legacy
  `compute/parallel.py` (multiprocessing) still present for the 3.0 path.
